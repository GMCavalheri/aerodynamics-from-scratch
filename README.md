# Aerodynamics From Scratch

[![CI](https://github.com/GMCavalheri/aerodynamics-from-scratch/actions/workflows/ci.yml/badge.svg)](https://github.com/GMCavalheri/aerodynamics-from-scratch/actions/workflows/ci.yml)

Classical and computational aerodynamics implemented from first principles in Python and
NumPy: thin airfoil theory, a 2D source/vortex panel method, an integral boundary layer with
transition and profile drag, and a 3D vortex lattice method — no CFD libraries, no XFOIL
wrappers. Every solver is validated against exact solutions, classical theory, or published
wind-tunnel data.

## What's inside

| Module | Method | Validated against |
|---|---|---|
| [`thin_airfoil`](src/aero/thin_airfoil) | Glauert Fourier series for any camber line | parabolic arc (closed form), NACA 2412 (Anderson) |
| [`panel_method_2d`](src/aero/panel_method_2d) | Hess–Smith constant source + vortex panels, Kutta condition | circular cylinder and Joukowski airfoil (exact), NACA 0012/2412 data |
| [`boundary_layer`](src/aero/boundary_layer) | Thwaites → Michel transition → Head turbulent → Squire–Young drag | Blasius, Howarth, Hiemenz, 1/7-power law, NACA 0012 drag |
| [`vortex_lattice_3d`](src/aero/vortex_lattice_3d) | Horseshoe VLM, Trefftz-plane induced drag; Glauert lifting line | Prandtl's elliptic wing, Kinner's circular wing, Bertin's swept wing |
| [`geometry`](src/aero/geometry) | NACA 4-digit and Joukowski airfoils | Abbott & von Doenhoff |

## Headline results

| Benchmark | Computed | Reference |
|---|---|---|
| NACA 2412 zero-lift angle (thin airfoil / panel) | −2.08° / −2.15° | −2.1° measured |
| Joukowski airfoil $c_l$, 800 panels | 1.2069 | 1.2181 exact (−0.9 %) |
| Howarth retarded flow, laminar separation | x = 0.123 | 0.120 exact |
| Elliptic wing span efficiency, AR 4–20 | 0.998–1.000 | 1 (Prandtl) |
| Circular wing lift slope | 1.781 /rad | 1.790 /rad (Kinner) |
| Optimum taper ratio, AR 8 | 0.45 (VLM), 0.375 (lifting line) | ≈ 0.35–0.4 |

Full comparison, figures and a discussion of every discrepancy:
**[validation report](docs/validation-report.md)**.

## Quickstart

Requires [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run pytest
```

```python
import numpy as np
from aero.panel_method_2d import solve_airfoil
from aero.boundary_layer import viscous_drag
from aero.vortex_lattice_3d import Wing, solve_vlm

alpha = np.radians(4)

sol = solve_airfoil("NACA 2412", alpha, n_panels=200)  # inviscid section
print(f"cl = {sol.cl:.3f}, cm_c/4 = {sol.cm:.3f}")  # cl = 0.743, cm_c/4 = -0.060

bl = viscous_drag(sol, re=3e6)  # boundary layer + drag
print(f"cd = {bl.cd:.5f}, transition x/c = {bl.upper.x_transition:.2f}")

wing = Wing.tapered(aspect_ratio=8, taper=0.4, sweep=np.radians(25))
s = solve_vlm(wing, alpha)  # finite wing
print(f"CL = {s.CL:.3f}, CDi = {s.CDi:.5f}, e = {s.span_efficiency:.3f}")
```

Regenerate every figure and results table, and the executed notebooks:

```bash
uv run python validation/run_all.py
```

```bash
uv run python notebooks/build_notebooks.py
```

## Conventions

Nondimensional throughout (chord = 1, $V_\infty$ = 1), angles in radians, airfoil points
clockwise from the trailing edge, body axes x downstream / y starboard / z up. See
[CLAUDE.md](CLAUDE.md) for contributor conventions.

## Scope and limits

Potential-flow solvers are inviscid and linear where noted; the boundary layer is not coupled
back to the outer flow, so there is no stall prediction. See each theory note's "Limits"
section. Planned extensions: a 2D finite-volume Euler solver and unsteady VLM.
