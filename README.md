# Aerodynamics From Scratch

A from-scratch implementation of classical and computational aerodynamics in Python/NumPy —
thin airfoil theory, a 2D panel method, an integral boundary layer, and a 3D vortex lattice
method — with no black-box CFD libraries. Every solver is validated against closed-form
results or published data.

> Work in progress. See [the project plan](AERO-01-aerodynamics-from-scratch-PLAN.md).

## Quickstart

```bash
uv sync
uv run pytest
```
